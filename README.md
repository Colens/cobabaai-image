
这是一个 NextJS 项目

这是一个使用 GPT-4o Image 批量绘画的开源软件，支持批量图片下载

使用在线版本：<a title="cobabaai">https://cobabaai.com</a>

或

自行安装

安装命令

```bash
npm install

npm run dev
```

这里推荐一个稳定便宜的 GPT Image API 网站 https://cobabaai.com

CobabaAI 提供多模型聚合 API，价格低廉，稳定可靠

使用方式

第一步，获取 API Key

打开: <a title="cobabaai">https://cobabaai.com/console/token</a>

第二步

登录后点击 API Key 栏目，点击创建 API 秘钥，然后复制下来。

第三步

回到网站里，把 API Key 设置到网站中。

接下来就可以刷图了。
